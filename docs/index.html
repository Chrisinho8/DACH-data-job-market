What this does not tell you

  • Postings are not hires. An old posting may be a real unfilled role, a pipeline-building advert, or a listing nobody took down.
  • One job board is not the whole market. This is Adzuna's German index, which aggregates many boards but not all of them.
  • Reposts are detected by content hash (title, company, city, first 200 characters). Genuinely distinct roles with identical wording would be merged.
  • Agency detection is keyword based and will miss agencies with neutral names.
  • Tool mentions are dictionary based and limited by description truncation, as noted above.
