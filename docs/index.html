How stale is the German data job market?

Every week I pull live data-job postings from a public API, run them through a Delta Lake pipeline on Databricks, and measure the one thing job boards never show you: how long these "live" jobs have actually been open.

How old is a "live" posting?

Days between the posting date and today, for jobs currently listed as open. The average is 59 days. The median is 17. That gap is the whole story: half the market moves in under three weeks, and a long tail of very old listings drags the average up by a factor of three.

How many are still open after N days?

A survival curve. Read it as: of every 100 live postings, how many have already been open at least this long. The steep drop in the first month is healthy churn. The flat tail after 60 days is what the average is really measuring.

Most mentioned tools read the caveat

The API hard-caps descriptions at 500 characters and 99.6% of postings are truncated. So this measures tools mentioned in the title or opening paragraph, not tools required. These are floors, not requirement rates. The truncation window is identical for every posting, so comparisons between tools hold; absolute percentages do not.

What this does not tell you

  • Postings are not hires. An old posting may be a real unfilled role, a pipeline-building advert, or a listing nobody took down.
  • One aggregator is not the whole market. This is Adzuna's German index, which covers many boards but not all of them.
  • The posting date is Adzuna's, which may be when it indexed the job rather than when the employer published it.
  • Reposts are detected by content hash (title, company, city, first 200 characters). Genuinely distinct roles with identical wording would be merged.
  • Seniority and role are inferred from the title with keyword rules, so both carry classification error.
  • Agency detection is keyword based and undercounts.
  • Tool mentions are limited by truncation, as described above.
  • Only aggregates are published here. Individual listings are not redistributed.
